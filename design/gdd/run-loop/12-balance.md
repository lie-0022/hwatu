# 12. 밸런스 (Balance)

## 1. Overview
튜닝 노브 모음 + 현재 MVP 수치. 플레이테스트로 반복 조정(SPEC §11.6).

## 3. 현재 수치 (MVP)
- **광객**: HP 80 · 골드 99 · 에너지 3 · 손패 5 · 시작 덱 10(빛타격×5/방패×4/점화×1).
- **카드 풀**: 광객 23장(빛/공격/방어 + Exhaust/Retain/Innate/Ethereal/다회 + 여명[방5광1]/광파[공9광2]) · 묵귀 16장(독/약화 + 키워드 + 고독[독3약1]/부식[공8독4]). 시작 덱 10장. `CharacterPools`로 캐릭터별 분기.
- **status 5**: Radiance · Weak(×3/4) · Vulnerable(×3/2) · Poison(턴틱) · Dexterity(방어+). **키워드 4**: Exhaust · Retain · Innate · Ethereal.
- **적 14**: 일반8(잡도깨비12~16·까마귀10~14·허수아비14~18·도깨비불9~13[Poison]·장승16~20[방어]·그슨대13~17·멧돼지20~26[자버프광+2→들이받기]·두꺼비24~30[방어10/독공]) · 엘리트3(광귀30~38[Vuln]·외눈도깨비32~40[Buff]·구렁이) · 보스3(달그림자45~55·구미호48~58[Doom]·장군, PhaseAi HP광폭).
- **캐릭터 2**: 광객(HP80,radiance) · 묵귀(HP70,poison). **유물 11**(전투시작; +떡방3/호리병광1방3/먹광1민1). **포션 7**(+강심약광3방6/선약HP30)+피티(40%±10).
- **보상**: Rare 3%/Uncommon밴드 37%(엘리트 10/40, 보스 Rare). 오프셋 −5~+40(+1/카드).
- **맵**: 7×15·6경로. 엘리트 8%/휴식 12/이벤트 22/상점 5%.
- **휴식**: 최대 HP 30% 회복. **액트 전환**: 부족분 100% 회복. **액트 수**: 3.

## 7. Tuning Knobs (전부)
캐릭터 HP/골드/덱 · 카드 수치·코스트 · 적 HP/패턴 · 보상 확률·골드·유물 가격 · 맵 노드 확률 · 액트 수 · 휴식/액트 회복률 · 업그레이드 증가폭.

## 8. Acceptance Criteria
- 현재 수치는 시작점. 밸런스는 플레이테스트 반복으로 수렴(콤보 쾌감·운 아닌 실수·"한 판 더").

## 후속
플레이 데이터 기반 조정 · 어센션(난이도) · 카드/적 추가 시 밸런스 패스 · 자동 시뮬 밸런싱(헤드리스 AI 대전).
