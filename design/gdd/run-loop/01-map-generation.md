# 01. 맵 생성 (Map Generation)

> 출처: [sts_map_oracle](https://github.com/Ru5ty0ne/sts_map_oracle)(원본 복제) · [Map Generation wiki.gg](https://slaythespire.wiki.gg/wiki/Map_Generation). 골격은 STS 그대로, 명칭/비주얼만 화투화.

## 1. Overview
액트 1장을 절차적으로 생성한다. 7×15 그리드 위에 6가닥의 경로를 바닥→꼭대기로 긋고, 경로가 닿은 노드에 방 타입을 배정한 뒤, 모든 경로를 단일 보스로 수렴시킨다. 시드 결정론(같은 시드=같은 맵).

## 2. Player Fantasy
액트 시작 시 **전체 맵이 보인다**. 플레이어는 엘리트·휴식·상점·보물의 위치를 미리 읽고 "어느 길로 갈지"를 설계한다. 맵 선택 자체가 핵심 의사결정.

## 3. Detailed Rules
- **그리드**: 폭 `W=7`, 높이 `H=15`. 경로 수 `density=6`.
- **고정 층**(타입 확정): 행0=전투, 행8=보물, 행14=휴식, 행15 위=보스(행14 전부 보스로 수렴).
- **비고정 노드 타입**: 엘리트/휴식/상점/이벤트/전투(아래 확률).
- **배치 제약**:
  1. 행 ≤ 4: 휴식·엘리트 금지.
  2. 행 ≥ 13: 휴식 금지(행14 고정 휴식과 분리).
  3. 부모(바로 아래 연결 노드)와 같은 타입 금지: 휴식/보물/상점/엘리트.
  4. 형제(같은 부모 공유)와 같은 타입 금지: 휴식/보물/상점/엘리트 + 전투/이벤트.
- **경로/분기**:
  - 행0에서 무작위 시작. **첫 2경로의 시작 노드는 서로 다름**.
  - 매 스텝 위 행의 좌/중/우(±1, 가장자리는 한쪽)에서 택1.
  - 같은 부모의 두 출구는 서로 다른 목적지.
  - 경로 안 닿은 노드는 제거.
- **이동(런타임)**: 현재 노드에서 **위로 연결된 노드만**, 단방향, 되돌리기 불가.

## 4. Formulas
- 타입 목표 개수 = `round(p × N)` (N=배정 가능 노드 수).
  - 엘리트 `p=0.08`(난이도≥1 시 `×1.6`), 휴식 `0.12`, 이벤트 `0.22`, 상점 `0.05`, 나머지=전투.
- 좌/중/우 선택: `x==0 → {0,+1}`, `x==W-1 → {-1,0}`, else `{-1,0,+1}`.
- 교차 금지(단조성): `new_x ≥ max(왼쪽 이웃의 dst_x)`, `new_x ≤ min(오른쪽 이웃의 dst_x)`로 클램프.
- 조상 충돌: 후보가 현재 노드와 **3행 이내** 공통 조상을 가지면 바깥으로 방향 보정.
- `?`(이벤트) 진입 결과 pity: 보물 2%(+2)/상점 3%(+3)/전투 10%/나머지 이벤트. 나오면 리셋.

## 5. Edge Cases
- 경로가 한 노드도 안 닿으면 그 노드 제거(렌더/이동 대상 제외).
- 첫 행 목적지 중복 간선은 사후 제거.
- 모든 경로가 행14 → 보스로 수렴(보스 도달 불가 노드 0 보장).
- density=6이어도 좌우 클램프로 경로가 겹치면 실효 경로 수 < 6 가능(정상).

## 6. Dependencies
- `IRandom`(시드 RNG, `Hwatu.Core.Rng`) — 결정론 생성.
- `MapNode`/`MapGraph`/`NodeType`(신규 `Hwatu.Core.Run`).
- 소비처: 맵 UI(렌더), RunState(현재 위치), 노드 해결(전투/보상 분기).

## 7. Tuning Knobs
- `Width=7`, `Height=15`, `PathDensity=6`.
- 타입 확률(엘리트/휴식/이벤트/상점) + 난이도 배수.
- 고정 층 인덱스(보물=8, 휴식=14).
- 제약 행 임계(휴식/엘리트 금지 ≤4, 휴식 금지 ≥13).

## 8. Acceptance Criteria
- [ ] 같은 (시드, 액트) → 완전히 같은 맵(결정론).
- [ ] 행0의 모든 시작 노드에서 보스까지 도달 경로 존재(연결성).
- [ ] 배치 제약(3·6번) 위반 0건.
- [ ] 고정 층(0/8/14/보스) 타입 정확.
- [ ] 간선 교차 없음(단조성 유지).
- [ ] 헤드리스 테스트로 위 전부 검증.
