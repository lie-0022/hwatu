# 족보 전투 설계 — 화투 로그라이크 대개편 (v0.1)

> **목적**: 단일 카드 플레이(STS 클론)를 버리고, **한 번에 여러 장을 "족보"로 내는** 전투로 전환한다.
> **공식**: 고스톱 족보(원전) × Balatro의 콤보 루프(검증된 재미) × STS의 적 인텐트(긴장).
> **원전 레퍼런스**: `화투_룰_정리.md` (카드 구성·족보·점수). 기존 전투 스펙(`화투_로그라이크_SPEC.md` §3.2·§5)은 본 문서가 대체하며, 확정 후 SPEC을 개정한다.
> 수치는 전부 **baseline(v0)** — `JokboRules` config로 분리해 BalanceSim으로 튜닝한다(고스톱 룰 변형이 크다는 원칙 그대로).

---

## 0. 한 줄 정의

**"손패에서 화투 카드 여러 장을 골라 족보를 완성해 내면, 족보가 클수록 강한 효과가 터지는 로그라이크 덱빌더."**
고스톱에서 같은 월을 "먹듯" 페어가 기본기, 홍단·고도리·삼광이 필살기, 오광이 런의 꿈.

## 1. 디자인 목표 / 비목표

**목표**
1. 화투가 스킨이 아니라 **시스템**이 된다 — 월·종류·족보·끗수가 곧 전투 문법.
2. "족보를 완성해 가는 손패 관리"가 매 턴의 고민이 된다(다음 턴 홍단 vs 지금 방어).
3. 적 인텐트가 족보 셋업을 압박한다 — Balatro에 없는 긴장.
4. 기존 자산(적/AI/인카운터/맵/상태이상/위엄·각성/유물 틀)을 최대 재사용.

**비목표(이번 개편에서 안 함)**
- 고스톱의 대전 요소(상대 손패, 바닥패 뺏기)를 그대로 재현 — 전투 번역만 취한다.
- 실시간/멀티. 뻑·설사 같은 "실패 함정"의 직역(전투에 억지).

## 2. 카드 모델

카드 = **월(1~12) × 종류(광/열끗/띠/피)**. 기존 "고유 텍스트 카드" 63장은 은퇴하고, 카드의 정체성은 원전 48장 구성표(`화투_룰_정리.md` §2.1)를 따른다.

| 종류 | 역할(효과 성질) | 기본치(v0) | 원전 끗수 |
|---|---|---|---|
| 광(光) | 강공격 | 공격 8 | 20끗 |
| 열끗(動物) | 공격 | 공격 6 | 10끗 |
| 띠(短) | 공격(+명명 족보 시 상태이상) | 공격 4 | 5끗 |
| 피(皮) | 방어 | 방어 3 | 1끗 |
| 쌍피 | 방어 | 방어 6 | 피 2장 취급 |

- 카드 데이터: `월, 종류, 기본치, 쌍피 여부, 인챈트(강화)`. 텍스트 효과 없음 — **효과는 족보가 결정**.
- 띠의 세부(홍단/청단/초단/비띠)와 열끗의 고도리 여부(2·4·8월)는 월에서 파생.
- 강화(+): 기본치 +2 (기존 휴식 강화·카드당 1회 규칙 유지).

## 3. 턴 경제 (에너지 폐지)

| 항목 | v0 값 | 비고 |
|---|---|---|
| 손패 | **8장 유지형** | 턴 시작마다 8장까지 리필. 낸/버린 카드만 소모 → "다음 턴 족보" 셋업이 성립 |
| 내기(Play) | **턴당 2회** | 1회 = 족보 하나(1~5장) 제출 |
| 버리기(Discard) | **턴당 2회** | 1회 = 원하는 장수 버리고 그만큼 드로우 |
| 에너지 | **폐지** | 내기/버리기 횟수가 자원. 유물/캐릭터로 증감 |

- 이월 없음(안 쓴 내기/버리기는 소멸).
- 적 턴·인텐트·상태이상 정산은 기존 CombatEngine 흐름 그대로.

## 4. 족보 체계

### 4.1 범용 족보 (월/종류 패턴 — 언제나 가능)

| 족보 | 구성 | 배수(v0) | 원전 대응 |
|---|---|---|---|
| 낱장 | 아무 1장 | **×1/2**(내림) | — (비상용 최소 플레이) |
| **먹기(페어)** | 같은 월 2장 | **×1** | 고스톱의 "먹기" — 기본기 |
| 같은 종류 셋 | 같은 종류 3장(월 무관) | ×3/2 | 모으기 점수(띠5·열끗5·피10)의 축약 |
| **흔들기** | 같은 월 3장 | ×2 | 흔들기(×2 배) |
| **폭탄** | 같은 월 4장 | ×3, **전체 공격화** | 폭탄(×2+피 강탈) |

### 4.2 명명 족보 (지정 카드 세트 — 필살기)

| 족보 | 구성 | 배수(v0) | 시그니처 효과(v0) | 원전 점수 |
|---|---|---|---|---|
| **홍단** | 1·2·3월 띠 | ×2 | + 적 화상(중독) 4 | 3점 |
| **청단** | 6·9·10월 띠 | ×2 | + 적 약화 2 | 3점 |
| **초단** | 4·5·7월 띠 | ×2 | + 적 취약 2 | 3점 |
| **고도리** | 2·4·8월 열끗 | ×2 | **3연타 분할** + 드로우 2 | 5점 |
| **삼광** | 광 3장(비광 제외) | ×3/2 **전체** | — | 3점 |
| 비삼광 | 광 3장(비광 포함) | ×1 **전체** | — | 2점 |
| **사광** | 광 4장 | ×2 **전체** | — | 4점 |
| **오광** | 광 5장 | ×3 **전체** | + 적 전체 약화 2 | 15점 |

- 명명 족보가 범용과 겹치면(예: 띠 3장이 마침 홍단) **더 높은 배수/명명을 우선** — 판정기는 항상 최고 족보를 선택.
- 오광은 덱에 광 5장을 모아야 가능한 **런 전체의 빌드 목표**(원전 15점의 위상).
- 예상 출력 예: 먹기(열끗6+피3)=공격6·방어3 / 홍단=(4×3)×2=공격24+화상4 / 고도리=(6×3)×2=36을 12×3연타+드로우2 / 오광=(8×5)×3=**전체 120**.

### 4.3 효과 해석 규칙

1. 낸 카드를 종류별로 합산: **공격합**(광+열끗+띠 기본치), **방어합**(피 기본치).
2. 각 합에 **족보 배수**를 곱한다(정수 분수 ×n/2·내림 — float 금지 결정론 유지).
3. 공격은 대상 1체(전체 족보는 전원), 방어는 자신. **위엄·광(Radiance) 가산, 약화/취약 보정은 기존 DamageMath 그대로**(다회 타격은 타격당 가산 — 고도리·위엄 시너지).
4. 명명 족보 시그니처(상태이상 등)를 마지막에 적용.

## 5. 고스톱 특수 규칙의 전투 번역

| 원전 | 채택 | 전투 번역 |
|---|---|---|
| 흔들기·폭탄 | **P0** | §4.1 족보로 흡수(같은 월 3장/4장) |
| 쪽·따닥 | P2 | 한 턴에 페어 2회 완성 시 보너스(드로우/내기+1) — "따닥 콤보" |
| 싹쓸이 | P2 | 손패를 정확히 0장으로 만들면 보너스 드로우 |
| 피박·광박 | P2 | **보스 기믹**: "이 전투에서 광 족보를 안 냈으면 받는 피해 ×2" 식 조건 압박 |
| 고/스톱 | P2 | 전투 승리 확정 시 "고"(한 턴 더 싸워 보상↑ vs 리스크) — 별도 설계 필요 |
| 뻑·설사 | 미채택 | 실패 함정의 직역은 전투에 부적합 |

## 6. 캐릭터 재해석 (족보 아키타입)

| 캐릭터 | 지향 족보 | 시작 덱 컨셉(12장 초안) | 고유 시스템 |
|---|---|---|---|
| **광객(빛)** | 삼광~오광·홍단 | 3월 광 1 + 홍단 재료 2(1·3월 띠) + 열끗 2 + 피 7 | 광(Radiance) 자원 유지 — 공격 족보 가산 |
| **묵귀(먹)** | 피 방어·초단 | 쌍피 1 + 피 6 + 초단 재료 2 + 열끗 3 | 중독 시너지 유지(초단·화상 증폭) |
| **백호 산군** | 고도리·흔들기 | 고도리 재료 2(2·4월 열끗) + 열끗 3 + 띠 2 + 피 5 | **위엄·각성 단계 그대로**(공격 족보에 위엄 가산) |

- 시작 덱에 명명 족보 재료를 **일부만** 넣어 "나머지 재료를 보상에서 모으는" 훅을 만든다(백호는 8월 열끗을 얻는 순간 고도리 해금).
- 광객의 상태 "광(Radiance)"과 화투 "광(光)패"의 **이름 충돌** 정리 필요 → §10 열린 결정.

## 7. 성장 축 (로그라이크 루프)

| 축 | 내용 |
|---|---|
| 카드 획득 | 보상 3택: 특정 월·종류 카드(예: "8월 열끗 — 고도리 재료!"). 희귀도 = 광 > 열끗·핵심 띠 > 피 |
| 카드 제거 | 상점 제거 — 덱 압축(족보 완성 확률↑)이 핵심 전략인 만큼 가치 상승 |
| 강화(+) | 기본치 +2, 카드당 1회(기존 규칙 유지) |
| **유물 = 조커** | 족보 배수·조건 강화가 유물의 새 역할. 예: "화로 — 홍단 화상 2배" / "북 — 흔들기 시 내기 +1" / "제기 — 페어 배수 ×3/2" / "골패 — 손패 +1" / "엽전꿰미 — 버리기 +1" |
| 기존 유물 17종 | 전투시작/턴시작/카드플레이(→족보 제출로 재해석)/HP임계 트리거 전부 호환 |

## 8. 기존 시스템 접점

**유지(무수정~경미)**: 적 데이터·AI 4종·인텐트·인카운터 맵 고정·맵 생성·상태이상 8종·DamageMath·위엄/각성·유물 트리거·포션·상점/휴식/이벤트 틀·RNG 결정론·EffectDispatcher.
**폐지**: 에너지, 카드 고유 텍스트(EffectData 카드), 기존 카드 63장(콘텐츠 은퇴 — 코드는 병행 기간 유지), 단일 PlayCard UI(드래그 타겟팅은 족보 제출 후 대상 선택으로 대체).
**재작성**: SimAi(족보 그리디 탐색), BalanceSim 시나리오, 카드 보상/상점 매물, CombatView 손패 UI.

## 9. UI 설계 (전투)

- 배치는 현행 **좌우 대치(STS식)** 유지.
- 손패 8장 부채꼴. **클릭 토글 선택**(선택 카드는 위로 떠오름).
- 선택이 바뀔 때마다 상단 중앙에 **족보 미리보기**: `홍단! — 예상: 피해 24 + 화상 4` (유효하지 않으면 "족보 없음" 회색).
- 버튼: **[내기 2/2] [버리기 2/2]** — 내기는 유효 족보에서만 활성. 단일 대상 공격 족보는 제출 후 적 클릭(기존 하이라이트 재사용).
- 낸 카드는 짧은 연출(족보명 배너) 후 버린 더미로.

## 12. 리스크

1. **밸런스 전면 재조정** — 플레이어 출력 곡선이 완전히 달라짐. J3 시뮬을 통과 기준으로 삼는다(기존 방법론 재사용).
2. **족보 완성 확률** — 덱이 커지면 명명 족보가 안 모임. 덱 압축·버리기·유물(드로우/손패+1)로 보정, 시뮬로 완성 빈도 측정.
3. **학습 곡선** — 고스톱 모르는 플레이어. 족보 미리보기·도감(족보표 hover)으로 완화.
4. **다중 적 압박** — 단일 공격 위주라 멀티가 어려울 수 있음 → 폭탄·광 계열 전체기와 인카운터(약체 멀티) 균형으로 해소.

## 부록. 한 줄 요약
**"먹기(페어)로 버티고, 홍단·고도리로 터뜨리고, 광을 모아 오광으로 판을 엎는다."** 카드 한 장의 텍스트가 아니라 **조합이 곧 카드**다.
