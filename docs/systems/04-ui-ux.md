# 04. UI/UX 현황 · 갭 · 툴팁 계획

> 2026-06-22. 사용자 피드백: **"기능은 많은데 어떤 능력인지, 된 건지 아닌 건지 알 수가 없다."**
> 현재 UI에서 무엇이 보이고 무엇이 안 보이는지 진단하고, 마우스 hover 설명/상호작용 피드백 추가 계획을 정리한다. (구현 전 — 함께 체크용)

## 1. 화면별 현재 UI 요소 (구현됨)

| 화면 | 보이는 것 |
|------|-----------|
| 메인 | 제목 · 시작 버튼 |
| 캐릭터 선택 | 광객/묵귀 버튼 |
| 맵 | 노드 그래프(분기) · HP/골드/액트 HUD · "덱 보기" 버튼 |
| 전투 | 적(이름·HP바·인텐트 색+수치) · 플레이어(HP바·에너지·광·방어 텍스트) · 손패 카드(이름·코스트·효과·키워드 라벨) · 포션 버튼(이름) · 턴 종료 |
| 보상 | 카드 3택1 · 포션 |
| 이벤트/휴식/상점 | 선택 버튼 · 매물 카드 · 덱 강화 그리드 |
| 결과 | 승/패 + 통계 · "메인으로" |

## 2. ⚠️ 갭 — "무슨 능력인지 모름" (불만 직결)

| 항목 | 현재 | 문제 |
|------|------|------|
| **유물** | 화면 표시 **전무** | 내가 뭘 가졌는지·무슨 효과인지 전혀 모름 (전투 시작 효과만 조용히 적용) |
| **status** (중독/약화/취약/광/민첩) | 텍스트 수치만 (광 N / 방어 N) | 각 status가 **무슨 뜻인지** 설명 없음. 적 status는 표시조차 약함 |
| **카드 키워드** ([소멸]/[선제]/[유지]/[휘발]) | 라벨만 | **의미** 설명 없음 |
| **포션** | 이름만 | 효과 hover 설명 없음 |
| **적 인텐트** | 타입 색 + 수치 | "무슨 행동(공격/방어/버프/파멸)"인지 색으로만 — 텍스트 보강 여지 |
| **상호작용 피드백** | 데미지 팝업 O | 구매/강화/포션 사용 시 "됐다" 확인이 약함 |
| **카드 hover** | 확대 + 들어올리기 O | 효과 텍스트는 보이나 키워드/status 의미는 여전히 모름 |

## 3. 툴팁/피드백 계획 (우선순위)

- **P1 — 공통 TooltipUI**: hover 시 마우스 근처 설명 박스(Show/Hide). 모든 hover 대상의 기반 인프라.
- **P1 — 유물 보유 바**: 전투/맵 HUD에 보유 유물 아이콘(또는 이름 칩) 나열 + hover 효과 설명. *가장 큰 구멍.*
- **P1 — status/키워드 사전 hover**: 중독=턴마다 피해 / 약화=공격 약화 / 취약=받는 피해 증가 / 광=공격력 / 민첩=방어 증가 / 소멸=사용 시 덱에서 제거 / 선제=첫 손패 보장 / 유지=턴 끝에 안 버림 / 휘발=안 쓰면 소멸.
- **P2 — 포션 hover 설명**, **적 인텐트 행동 한글 라벨 보강**.
- **P3 — 상호작용 토스트**: 구매/강화/포션 사용/유물 획득 시 짧은 확인 메시지.

## 4. STS2 UI 대비

- STS(1/2): **유물 상단 바 상시 + hover 설명**, **status 아이콘 + hover**, 카드/포션 hover 상세, 인텐트 아이콘+수치+hover. 정보가 전부 마우스로 확인 가능.
- 화투 격차: **유물 표시·hover 설명 체계가 통째로 빠짐** + status/키워드가 의미 없는 기호. → 본 계획(P1)이 핵심 격차를 메움.
- 화투 강점(유지): 화투 테마, Doom 카운트다운 텔레그래프, 캐릭터 2종 차등.

## 5. 함께 체크할 결정 사항

- 유물 바 위치: 전투 화면 상단? 맵 HUD 줄? 둘 다?
- 툴팁 트리거: hover만? (모바일 아니므로 hover로 충분)
- status 표기: 아이콘 신규 제작 vs 현행 텍스트 + hover 사전(아이콘 에셋 없이 가능).
- 우선순위: P1 셋 중 어디부터(유물 바 / status 사전 / 공통 Tooltip).
