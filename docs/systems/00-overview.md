## 완성도

- **코어 루프**: 메인 → 캐릭터 → 맵 → 전투 → 보상 → 이벤트/휴식/상점/보물 → 보스 → 2막 → 승/패 → 재시작. **전부 작동.**
- **검증**: EditMode 135 그린 + 헤드리스 시뮬(시작덱 일반/엘리트 100% · 보스 HP 절반 소모).
- **핵심 갭**: UI 정보 가독성(유물 표시 · hover 설명) — 사용자 불만 "뭐가 됐는지 모름"의 원인.
