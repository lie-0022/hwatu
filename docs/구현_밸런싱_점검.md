# 구현 콘텐츠 밸런싱 점검 & 백호 디벨롭

> 현재 코드에 **실제 구현된 값**을 감사하고, 슬더슬1·2 기준자 + 내부 정합성으로 **밸런싱 진단·권장값**을 제시한다.
> 코드 기준: `Assets/Hwatu/Core/` (Content/Combat/Effects/Run), 조사일 2026-06-23.
> ⚠️ **본 문서는 분석/권장만 — 코드는 수정하지 않음.** 적용은 별도 작업.
> 관련: `백호_카드밸런싱.md`(이상적 설계안) ↔ 본 문서(엔진 현실 반영). `docs/systems/`(기존 설계), `docs/research/`(StS 리서치).

## 0. 핵심 결론 (TL;DR)

1. **적 HP가 기존 설계문서보다 대폭 상향됨** (잡도깨비 12~16 → **코드 28~34**). → `docs/systems/05-balance-sim.md`의 승률표는 **stale**. 재측정 필요.
2. **캐릭터 카드 풀 불균형**: 광객 29 / 묵귀 24 / **백호 10**. 백호는 빌드 다양성이 절반 이하 → 확장 1순위.
3. **`Majesty`(위엄) 업그레이드 보너스 누락**: `Dexterity`는 +2인데 같은 류인 `Majesty`는 switch에 없어 **default +1**. 정합성 깨짐(권장: +2 그룹 편입).
4. **백호 전용 유물·키워드·둘째 축 부재**: 위엄과 시너지 나는 유물 0개, 백호 풀에 소멸/재생/가시/최대HP 없음. 아이언클래드式 깊이가 얕음.
5. **act 스케일이 HP만 ×1.25** (피해 미스케일) → 후반이 "더 아픈" 게 아니라 "더 질긴" 슬로그가 될 위험.
6. **플레이스홀더 유물 미작동**: 엽전꾸러미·등잔은 효과 없음(주석에 "후속").

## 1. 현재 구현 스냅샷 (감사)

### 1.1 전투 상수 (`PlayerState`, `CombatEngine`, `DamageMath`)
| 항목 | 값 | StS 대비 |
|---|---|---|
| 턴당 에너지 `BaseEnergy` | 3 | ✅ 동일 |
| 손패 드로우 `HandSize` | 5 | ✅ 동일 |
| Block | 턴마다 리셋 | ✅ |
| 데미지 공식 | `(기본 + Radiance + Majesty)` → 약화 ×3/4(공격자) → 취약 ×3/2(대상) → −Block, 음수면 0 | ✅ STS식 정수 결정론 |
| 중독 | 턴 시작 스택 피해(Block 무시) 후 −1 | ✅ |
| 재생 | 턴 시작 스택 회복(MaxHp 캡) 후 −1 | ✅ |

- **효과 op 8**: DealDamage · GainBlock · Draw · ApplyStatus · GainResource · ClearStatus · **ConsumeRadiance**(보유 광 전부 소비 → 소비량×amount 피해) · **MultiplyPoison**(독 ×amount). *(문서는 6으로 표기 — 코드가 최신, 8개)*
- **status 8**: Radiance(광=힘) · Weak · Vulnerable · Poison · Dexterity(방어+) · Regen · Thorns · **Majesty(위엄=백호 힘)**.
- **키워드 4**: Exhaust · Retain · Innate · Ethereal.

> 핵심: **Radiance와 Majesty 둘 다 모든 공격 피해에 가산**(DamageMath). 즉 위엄은 이미 "힘"으로 작동 중.

## 5. 적 밸런스 패스

### 5.1 곡선 진단 (vs StS, 플레이어 80HP)
- **일반 20~52 / 엘리트 52~70 / 보스 95~125** (act1 기준).
- StS2 act1: 엘리트 ~60~130, 보스 ~170~252. → 본작 **보스 HP가 상대적으로 낮음**(짧은 게임이라 의도 가능). 단 act3 보스도 ×1.5=142~187로 StS2 act1 보스 수준 → **후반 긴장 부족** 우려.
- 적 피해: 보스 16~32, 엘리트 14~17, 일반 9~13 → act1로 적정. **act 무관 고정**이 문제(G5).

### 5.2 권장
1. **act 피해 스케일 추가**: act2 ×1.10, act3 ×1.20 (HP만 키우는 슬로그 방지).
2. **보스 HP 곡선 강화**(선택): act3 보스 베이스 상향 또는 전용 act3 보스 세트.
3. **멧돼지/외눈/장군 자버프(광+2/+3)**: 위엄식 누적이라 장기전서 급증 → 연속 제한/상한 점검.
4. **두꺼비·구렁이 독 지구전**: 플레이어 회복 수단(광객 치유광/재생부적)과의 상성 확인.

## 7. 튜닝 노브 & 재측정 계획

### 7.1 노브 (값만 바꿔 곡선 조정)
| 노브 | 현재 | 영향 |
|---|---|---|
| 정기주입/멧돼지 위엄량 | +1 / +2 | 백호 스케일 속도 |
| Majesty 업그레이드 보너스 | +1(버그) | → +2 권장 |
| 발톱질 베이스 | 5 | 백호 초반 화력 |
| act HP 배율 | ×0.25/act | 후반 길이 |
| act 피해 배율 | 없음 | → 추가 검토(§5) |
| 어센션 HP/HP페널티 | +5% / −3 | 난이도 단계 |
| 보스 베이스 HP | 95~125 | 후반 긴장 |

### 7.2 BalanceSim 재측정 (G1)
- `BalanceSim.Simulate(deck, enemy, maxHp, trials)`로 **현재 적 HP 기준 재실행** → `05-balance-sim` 표 갱신.
- 측정 매트릭스: 3캐릭터 시작덱 × (일반 대표 3 + 엘리트 3 + 보스 3), 각 ≥50회.
- 백호 추가: 정기주입 투자 빌드(위엄 누적) 시 보스 TTK·승률.
- 합격선: 시작덱 일반 ≥90% / 보스 30~70%(절반 HP 긴장). >95% 너무 쉬움, <30% 너무 어려움(자동 플래그).
- **한계 보정**: SimAi가 공격 우선 휴리스틱(승률 하한). 방어·포션·다회 타깃 미반영 → 실제는 더 쉬움.

### 7.3 적용 순서 제안 (코드 작업 시)
1. (즉시·저위험) G3 Majesty 업그레이드 +2, G6 엽전꾸러미 실효화, 발톱질 6, 멧돼지의 기세 Uncommon.
2. (콘텐츠) §6.1 백호 7장 추가 → 풀 17.
3. (엔진 P1) 턴 시작 위엄 파워(신수의 격) → 백호 스케일 엔진.
4. (곡선) act 피해 스케일 + 보스 HP 재튜닝 → 시뮬 재측정 루프.
