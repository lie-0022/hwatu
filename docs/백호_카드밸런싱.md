# 백호 산군 — 카드 & 밸런싱 상세 계획

> `캐릭터_백호_산군.md`의 컨셉을 **실수치로 구현**하기 위한 밸런싱 문서.
> 모든 기준값은 **슬더슬1·2 실제 수치**에 맞춰 보정했다(출처 §10).
> 핵심 캐릭터 = **위엄(威嚴) = 힘(Strength) 스케일 브루저 + 자가 각성 변신**. 아이언클래드가 직접적 벤치마크.

---

## 0. 가장 중요한 설계 결정 (먼저 읽기)

1. **위엄(威嚴) = 슬더슬의 힘(Strength)과 동일 동작**.
   - 위엄 1 = **모든 공격 카드 피해 +1** (자동 적용). 다단히트는 **타격마다** 적용(예: 위엄 5 + 3회 공격 = +15).
   - 따라서 카드 텍스트에는 **기본 피해만** 적고, 위엄은 엔진이 자동 가산한다. (캐릭터 문서의 "(위엄+n)" 표기는 본 문서 기준 **기본값 + 자동 위엄**으로 대체)
   - **상한**: 위엄·피해에 `999,999,999` 클램프(StS2 무한 방지 차용).
2. **두 번째 축 = 최대 HP 성장**(거수 빌드). 위엄과 분리해 폭주를 분산(헤비블레이드式 단일 배수 + 최대HP% 피니셔).
3. **무한/지수 콤보는 의도적으로 절제**(StS2 철학): 위엄 2배 카드(군림)는 **소진+가격**으로 게이팅, 0코 루프 차단, 위엄 캡.
4. **각성 단계 = 위엄 임계치(5/10/15)** 로 트리거 → 위엄이 공격 스케일과 변신 게이지를 **겸한다**.

## 1. 기본 경제 (슬더슬과 동일하게 고정)

| 항목 | 값 | 근거(StS) |
|---|---|---|
| 턴당 에너지 | 3 | StS1/2 동일 |
| 턴 시작 드로우 | 5 | StS1/2 동일 |
| 시작 HP | **80** | 아이언클래드 80(최고). 백호=탱키 브루저로 적합 |
| 시작 덱 | **10장** (발톱질×5 + 웅크리기×4 + 내려찍기×1) | StS 스타터 5/4/1 구조 그대로 |
| 시작 유물 | **산군의 가호**: 전투 종료 시 HP **+6** 회복 | 아이언클래드 '불타는 피' 클론(안전한 기본 유물) |
| 카드 보상 | 전투 후 **3장 중 1택**(스킵 가능) | StS 동일 |

> 참고: 캐릭터 문서 §3의 시작 유물(위엄+2)은 영구 힘 스타터로 과도 → **본 문서 기준 '가호(회복)'로 확정**. 위엄 관련 효과는 유물 풀(§7)로 분산.

## 2. 카드 가치 벤치마크 (밸런싱 자)

> 이 표를 "에너지당 적정 효율"의 기준자로 사용. 신규 카드는 여기서 ±하여 희귀도/사이드이펙트로 보정.

| 코스트 | 단일 피해 | 방어도 | 비고 |
|---|---|---|---|
| 1E | **6~9** | **5~8** | 타격6→9 / 수비5→8 |
| 2E | **14** | ~13 | 헤비블레이드 14 |
| 3E | **32** | — | 박살 32(피니셔) |
| X코스트 | 전체 **5~8/E** | — | 회전베기 |
| 0E | 효과 약함 + 사이드이펙트 | | 분노·사혈 등 |

**강화(Upgrade) 관례**: +3 피해 / +3 방어 / 또는 **코스트 −1 / 소진 제거 / 드로우 +1** 중 택1. (StS 표준)

**희귀도 효율 곡선**:
- 커먼 = 템포·기본 효율. 언커먼 = 시너지·소콤보. 레어 = 빌드를 정의(스케일 엔진/피니셔).

## 3. 위엄(威嚴) 스케일 수학

### 3.1 위엄 공급원 (StS 대응)
| 카드/유물 | 위엄 | 코스트 | StS 대응 |
|---|---|---|---|
| 정기 주입(파워) | +2 → +3 | 1E | 발광(Inflame) |
| 으르렁(임시) | +2 → +4 *이번 턴만* | 0E | 플렉스(Flex) |
| 약점 포착 | +3 → +4 *(적 공격의도 시)* | 1E | Spot Weakness |
| 신수의 격(파워) | **매 턴 +2 → +3** | 3E | 악마의 형상(Demon Form) |
| 분노 각성(파워) | 카드로 HP 잃을 때 +1 → +2 | 1E | 파열(Rupture) |
| 군림(스킬) | **현재 위엄 ×2**, 소진(강화 시 소진 제거) | 1E | 한계돌파(Limit Break) |
| 산군의 인(유물) | 전투 시작 +1 | — | 바즈라(Vajra) |

### 3.2 한 판 위엄 곡선 (목표치)
- **Act1 보스(≈170~250 HP)**: 위엄 **4~8** 도달이 정상(정기주입 1~2 + 으르렁). 각성 **2단계** 진입.
- **Act2 보스(≈320~400)**: 위엄 **8~12**. 신수의 격 가동 시. 각성 **3단계**.
- **Act3 보스(≈400~512)**: 위엄 **12~18+**. 각성 **4단계(신수)**.
- → 각성 임계치 **5/10/15**는 이 곡선에 맞춰 "Act1 중반/Act2/Act3"에 자연 도달하도록 설정.

### 3.3 폭주 방지 (StS2 철학 반영)
- **군림(위엄 2배)**: 소진 기본 + 1E지만 **레어**로 희소화. 강화로 소진 제거 시에도 1장만 → 지수 루프 어려움.
- **신수의 격**(매턴 +)은 1장만 큰 효과; 중복 시 가산(지수 아님).
- 위엄 캡 `999,999,999`. 0코 카드로 위엄·에너지 동시 순환되는 조합은 풀에서 배제.
- 단일 배수 피니셔(헤비블레이드 클론)는 **배수 고정**(3배), 강화는 기본피해만 → 통제된 burst.

## 5. 각성(位階) 단계 — 임계치 튜닝

| 단계 | 위엄 | 패시브 | 밸런스 의도 |
|---|---|---|---|
| 1 | 0–4 | 기본 | 초반 |
| 2 | 5–9 | 매 턴 시작 위엄 +1 | Act1 중반 도달. 완만한 자가 가속 |
| 3 | 10–14 | 모든 공격 +25% | Act2 도달. 곱연산 1회로 화력 도약 |
| 4 | 15+ | 공격 전체 대상 + 받는 피해 25% 감소 | Act3 도달. 신수 피니시 |

- **+25%(3단계)·전체화(4단계)** 는 강력 → 임계치 10/15를 **투자 없이는 못 가게** 유지(정기주입·신수의 격 필요).
- 튜닝 노브: 임계치(5/10/15)와 2단계 자가 가속(+1/턴) 여부가 곡선 핵심.

## 6. 적 HP 기준 & 화력 목표 (DPS 캘리브레이션)

> 슬더슬2 보스 HP에 맞춘 "이 시점에 이 정도 화력이면 정상" 가이드.

| 시점 | 적 HP 기준(StS2) | 백호 권장 화력(턴당) |
|---|---|---|
| Act1 일반 | ~20~70 | 8~15 |
| Act1 엘리트 | ~60~130 | 15~25 |
| Act1 보스 | **170~252** | 25~40 |
| Act2 보스 | **320~400** | 40~60 |
| Act3 보스 | **400~512** | 60~90+ |

- 예) 위엄 10 + `산을 베다`(14 + 위엄3배=30 → 합 **40+**), 신수의 격으로 매 턴 누적 → Act2~3 보스 처리 가능.
- 거수 빌드: 최대 HP 120일 때 `산을 가르다` = **60 피해** 단발.

## 8. 보상 / 희귀도 분포 (StS 차용)

- 일반 전투 카드 보상 3장: **커먼 다수 / 언커먼 ≈ 33% / 레어 낮음(피티 상승)**.
- 엘리트: 레어 확률 +10%. 보스/보물: 유물(고대의 존재로 대체 가능, SPEC §3.1).
- 상점 카드: 커먼 54% / 언커먼 37% / 레어 9% 참고.
- MVP에서는 단순화: 커먼 60% / 언커먼 30% / 레어 10% 고정으로 시작.

## 9. 빌드 아키타입별 핵심 카드

1. **거수(성장 폭발)**: 정기주입·신수의 격·사슴의 가호·**산을 가르다**·산을 베다. (느림→한 방)
2. **수호(버티기)**: 가죽 단련·호위 자세·불굴·산울림. 약화/취약로 데미지 경감 + 야금야금. (보스 안정)
3. **야성(연타)**: 으르렁·쌍발톱·약점 포착·산을 베다. 위엄 빠르게 → 다단히트 폭발. (빠름)
4. **분노 자해(서브)**: 분노 각성·사혈·물어뜯기·광혈. HP→위엄 환전(StS2 블러드레팅 차용).

## 10. MVP 구현 카드 부분집합 (먼저 만들 ~16장)

발톱질, 웅크리기, 내려찍기(기본 3) + 정기주입, 쌍발톱, 산울림, 어깨치기, 으르렁, 포효(소)(커먼 6) + 산을 베다, 약점 포착, 선풍참, 가죽 단련, 사슴의 가호, 대포효, 호위 자세(언커먼 7) + 신수의 격, 산을 가르다(레어 2).
→ 거수/수호/야성 3축을 모두 맛볼 수 있는 최소 세트. (자해·각성 4단계·유물 전체는 후순위)
